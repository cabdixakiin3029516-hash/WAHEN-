# WaHeN Flutter App

This is a small Flutter starter app for the WaHeN marketplace.

## Run locally

1. Install Flutter SDK.
2. Open the project folder:
   ```bash
   cd flutter_app
   flutter pub get
   flutter run
   ```

## Included features

- product listing with categories
- search bar
- add to cart
- favorites toggle
- order tracking screen
- buyer/shop flow

## Notes

This is a mobile-first MVP. You can later expand it with:
- login/signup
- seller dashboard
- admin panel
- payment gateway integration
- live chat
- backend/API integration
